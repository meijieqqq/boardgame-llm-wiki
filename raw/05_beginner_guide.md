# 陣營推理新手常見五大誤區與破冰心法

剛接觸陣營推理遊戲的新手，常因為害怕說錯話或暴露身分而陷入被動。以下整理五個最常見的新手誤區，以及能立刻套用的破冰策略。

## 五大常見新手誤區
1. **過度沉默與「划水」**：許多新手以為「少說話就不會出錯」，但在陣營遊戲中，不提供任何資訊的玩家（俗稱划水）會讓好人無法判斷你的立場，反而成為最容易被優先投票淘汰的對象。
2. **好人憑直覺亂帶風向**：在沒有掌握明確線索時，僅因為「某人看起來很緊張」就強烈號召大家投票淘汰他，容易誤傷關鍵神職或忠臣，替壞人免費清除對手。
3. **只聽口頭承諾，忽略客觀紀錄**：新手容易被口才好的玩家說服，卻忘記回頭核對「他在上一輪投了誰的票」或「他跟誰組過任務隊伍」。行為紀錄永遠比口頭表態誠實。
4. **拿到關鍵角色時過度緊張露餡**：第一次抽到壞人或梅林時，語速突然變快、眼神閃躲，或者刻意過度熱心解釋，反而形成明顯的「狀態反差」。
5. **陷入情緒化爭執而非邏輯盤點**：當被其他玩家懷疑時，只會急著喊「我真的是好人，你們不信我也沒辦法」，這種情緒性防禦無法提供任何推理價值，還會降低可信度。

## 新手快速上手的三個破冰心法
1. **套用三段式發言模板**：輪到你發言時，只要講清楚三件事就算及格——**「我的身分立場（我是好人）＋ 我觀察到的客觀事實（誰的投票或出牌有矛盾）＋ 我建議這輪的行動（我建議投誰或組誰）」**。
2. **養成記錄關鍵節點的習慣**：在心中或紙上只記兩件事：「誰跟誰互相保過（綁定關係）」以及「誰跟誰互相對立（互斥關係）」。只要其中一人身分揭曉，另一人的陣營就會立刻水落石出。
3. **把被懷疑當成推理的一部分**：被懷疑是陣營遊戲的常態。冷靜回應對方的質疑點，並反問：「如果我是壞人，我上一輪為什麼要做出對壞人不利的投票？」用邏輯反證取代情緒辯解，就能迅速建立場上公信力。
