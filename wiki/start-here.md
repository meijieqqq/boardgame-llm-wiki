# 從這裡開始：陣營推理是什麼？

## 一句話理解

陣營推理遊戲（Social Deduction Game）是一類讓玩家依據不完整資訊、公開行動與彼此互動，判斷隱藏身分或完成陣營目標的遊戲。可以把它想成一場「線索不完整的團隊解謎」：大家看到相同的部分紀錄，卻未必知道彼此掌握了什麼。

## 先認識幾個詞

| 詞語 | 白話意思 |
|---|---|
| 陣營 | 目標相同的一組玩家；例如阿瓦隆的藍方與紅方。 |
| 身分／角色 | 玩家拿到的隱藏或公開人物設定；有些角色會額外提供資訊或能力。 |
| 隱藏身分 | 其他玩家一開始看不見的角色或所屬陣營。 |
| 資訊不對稱 | 玩家知道的事情不一樣；有人掌握角色資訊，有人只能根據公開紀錄推測。 |
| 知情玩家 | 已經知道某些玩家或事件資訊的人；知情程度由遊戲規則決定。 |
| 公開行動 | 其他玩家也能觀察或事後核對的行為，例如投票、組隊、出牌或發言。 |
| 表決／投票 | 玩家用票決定是否接受隊伍、放逐玩家或採取其他行動；具體用途依遊戲而異。 |
| 欺瞞／唬騙 | 玩家刻意隱藏或扭曲資訊以達成目標的行為；不代表每個可疑行為都能證明其身分。 |

## 不同遊戲不一定同一種結構

阿瓦隆與狼人殺有對立陣營及隱藏角色；《情書》則主要是依牌面效果與手牌資訊競爭，適合用來練習推理，但不是典型的好人對壞人陣營配置。勝利條件、淘汰方式與資訊規則都要以各遊戲規則為準。

核心機制資料將好人描述為「知情少數」、壞人描述為「知情多數」，但同一批資料的阿瓦隆與狼人殺例子呈現的是壞人彼此知情、一般好人資訊較少。為避免把兩個標籤誤當通則，本 Wiki 改用「知情玩家／資訊較少的玩家」描述資訊差異；玩家人數和知情分布應查閱個別遊戲規則。參見[隱藏資訊與身分](hidden-information.md)。
